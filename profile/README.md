## Offe Consulting AB

Offe Consulting AB builds **mcpbus**.

### mcpbus

mcpbus is a local gateway for Windows that controls what AI agents can do in SQL Server and PostgreSQL. It runs as an MCP server on your own machine. You choose which databases an agent sees and at what level (schema, read or read/write), and by default every write needs your approval before it runs.
